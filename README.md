# IBM-HR-Analytics-SQL-Project
SQL analysis of IBM HR Analytics Employee Attrition dataset with business insights.


## Project Overview
This project analyzes the IBM HR Analytics Employee Attrition dataset using SQL to identify key factors influencing employee attrition. The analysis answers important HR business questions and provides actionable insights for improving employee retention.

---

## Dataset
- Dataset: IBM HR Analytics Employee Attrition
- Total Employees: 1,470
- Tool Used: MySQL

---

## Business Questions Answered
- Which department has the highest attrition?
- Which age group has the highest attrition?
- Which education field has the highest attrition?
- Does overtime increase employee attrition?
- Which salary slab has the highest attrition?
- Which experience group has the highest attrition?
- Does gender influence attrition?
- Which employees earn above the average salary?

---

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- CASE WHEN
- Aggregate Functions
- Subqueries
- ROUND()
- Aliases

---

## Key Insights
- Employees aged **18–25** had the highest attrition rate.
- Employees working **overtime** showed significantly higher attrition.
- **Low-salary employees** experienced the highest turnover.
- **New employees** were more likely to leave than long-tenured employees.
- HR and Technical Degree education fields recorded comparatively higher attrition.

## Dashboard
HR Attrition Dashboard built in Power BI. It shows total employees, employees who left,
and the attrition rate, with slicers for department, age group, and overtime.

![HR Attrition Dashboard](dashboard/overview.png)

Key findings:
- Overall attrition is 16.1% (237 of 1,470 employees).
- Employees who work overtime leave far more often: 30.5% vs 10.4%.
- Employees under 30 have the highest attrition by age group, at 27.9%.
- Sales has the highest attrition by department, at 20.6%.
